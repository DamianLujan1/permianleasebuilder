      1. Job board: take a ticket. Each job ties a lease into the one central tank battery (CTB) — or runs it.
      2. Wells flow on Christmas trees (no artificial lift). Set a Test Site out by the pads (6-well test manifold + test separator) and a Header (4 lines) inside the CTB fence.
      3. Dig from each orange flag stake to a tile beside the test site, then from the test site to a tile beside the header. Keep the pad ditches and the bulk-line ditch from touching. Stay off the caliche pit's flagged setback, power poles & pipeline markers; road and ROW crossings cost 4× / 8×. Longer lines = more backpressure.
      4. Lay Pipe (first ~90 ft off each wellhead is welded steel, the rest is flexpipe; the bulk line is flexpipe), Backfill, then set & Connect vessels upstream → downstream. Gas is your call: a Gas Sales Meter on the fence (revenue), a Flare (cheap, $0 gas), or both with the flare as backup. Watch the Build review.
      5. Commission → operations: haul trucks, alarms (click the flashing !), then the report card.
